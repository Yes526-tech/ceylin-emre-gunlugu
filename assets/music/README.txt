# MÜZİK DOSYASI BİLGİSİ

Şarkı: Ufuk Beydemir - Ay Tenli Kadın

Orijinal şarkının çalması için:
1. Şarkının mp3 dosyasını bu klasöre atın.
2. Dosya adını `ay_tenli_kadin.mp3` yapın.

Web sitesi otomatik olarak bu dosyayı algılayacak ve orijinal kaydı çalacaktır.
Eğer mp3 dosyası eklenmezse, site yerleşik akustik arpej melodisini çalmaya devam eder.
