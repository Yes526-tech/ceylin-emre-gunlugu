# FOTOĞRAFLARI EKLEME REHBERİ

Ceylin'e özel fotoğrafları eklemek için bu klasördeki görselleri kendi fotoğraflarınla değiştirebilirsin:

1. hero.jpg   -> Ana karşılama ekranındaki büyük kapak fotoğrafı
2. photo1.jpg -> Galeri 1. fotoğraf (Örn: İlk buluşma / İlk fotoğrafımız)
3. photo2.jpg -> Galeri 2. fotoğraf (Örn: En sevdiğim gülüşün)
4. photo3.jpg -> Galeri 3. fotoğraf (Örn: Birlikte geçirdiğimiz güzel bir gün)
5. photo4.jpg -> Galeri 4. fotoğraf (Örn: Unutulmaz bir anı)
6. photo5.jpg -> Galeri 5. fotoğraf (Örn: Tatilden veya özel bir günden)
7. photo6.jpg -> Galeri 6. fotoğraf (Örn: En tatlı selfie)

İpuçları:
- Fotoğraflarını buraya attığında aynı isimleri (hero.jpg, photo1.jpg, ...) verirsen site otomatik olarak senin fotoğraflarını gösterecektir.
- Ayrıca web sitesindeki "Fotoğraf Yükle / Önizle" butonunu kullanarak da tarayıcında anında yeni fotoğraflar ekleyebilirsin!
